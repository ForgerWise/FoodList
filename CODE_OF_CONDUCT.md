# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give constructive feedback, and no harassment of any kind.

Report unacceptable behaviour to [forgerwise@gmail.com](mailto:forgerwise@gmail.com). All reports are handled confidentially.
